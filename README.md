# 어디서 만날까

친구들이 각자 다른 곳에서 출발해도, 가장 늦게 도착하는 사람의 이동시간이 최소가 되는
"가장 공평한" 만남 장소를 찾아주는 웹앱. 대중교통과 자차 이동을 각자 선택할 수 있다.

## 동작 방식

1. 친구별 출발지(주소 검색)와 이동수단(대중교통/자차)을 입력
2. 서버가 모든 출발지의 중심점을 구하고, 그 주변 지하철역들을 후보 장소로 삼음
3. 각 후보 장소에 대해 친구별 실제 이동시간을 계산 (자차 = 카카오모빌리티, 대중교통 = ODsay)
4. 후보 중 "가장 늦게 도착하는 사람의 이동시간(최댓값)"이 가장 작은 곳을 1순위로 추천

## 시작하기

```bash
npm install
cp .env.local.example .env.local
```

`.env.local`에 아래 키를 채워 넣는다.

| 키 | 용도 | 발급처 |
| --- | --- | --- |
| `NEXT_PUBLIC_KAKAO_JS_KEY` | 지도 표시, 장소 검색 | [카카오 개발자 콘솔](https://developers.kakao.com) → 애플리케이션 추가 → 앱 키 → JavaScript 키. **제품 설정 > 카카오맵**에서 상태를 ON으로 켜고, 플랫폼 키 > JS 키 상세 화면의 "JavaScript SDK 도메인"에 `http://localhost:3000` 등록 필요 |
| `KAKAO_REST_API_KEY` | 주소/카테고리 검색, 자차 길찾기 | 같은 앱의 REST API 키. **자차 소요시간**을 실제로 계산하려면 콘솔에서 카카오모빌리티(길찾기) 제품을 추가로 활성화해야 함 |
| `ODSAY_API_KEY` | 대중교통 길찾기 | [ODsay Lab](https://lab.odsay.com) 회원가입 후 애플리케이션 등록 (서비스 유형: Basic/무료, 플랫폼: URI로 `http://localhost:3000` 등록) 후 발급. Basic 무료 티어는 하루 호출량이 적으므로(약 30회) 친구 수가 많으면 금방 소진될 수 있음 |
| `ODSAY_REGISTERED_URI` | ODsay가 URI 플랫폼으로 검증할 때 보낼 Referer 값 | 위에서 등록한 URI와 동일하게. 기본값 `http://localhost:3000` |

키를 채운 뒤 개발 서버 실행:

```bash
npm run dev
```

http://localhost:3000 접속.

## 참고

- 카카오모빌리티 길찾기 권한이 없거나 ODsay 키가 없으면, 해당 이동수단의 소요시간은
  직선거리 기반 추정치로 대체되고 결과에 "(추정)" 표시가 붙는다. 앱은 계속 동작하지만
  정확도는 떨어진다.
- 후보 장소는 출발지들의 중심점 반경 내 지하철역 위주로 생성한다. 지하철이 드문
  지역에서는 후보가 적게 나올 수 있다.
- 친구가 3명 이상이면 각 후보마다 (후보 수 × 친구 수)만큼 외부 API를 호출하므로,
  친구 수가 많을수록 계산 시간과 API 호출량이 늘어난다.
